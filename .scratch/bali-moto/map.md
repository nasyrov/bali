# Bali Moto — wayfinder map

Label: wayfinder:map
Tracker: local markdown (`.scratch/bali-moto/`)

## Destination

A build-ready spec for a browser game where you ride a motorbike freely across the whole island of Bali on real roads, with the current named area (Canggu, Kuta, Ubud…) shown on screen, live traffic, and a day/night cycle. Every design and tech decision is locked and written up so `/to-spec` and `/to-tickets` can turn it into implementation work. No game code is built during wayfinding; only prototypes.

## Notes

- Domain: single-player, free-roam, arcade-feel motorbike exploration. No fail state, no missions. Traffic and day/night are atmosphere, not obstacles to beat.
- Platform: desktop browser, keyboard only, static hosting. TypeScript with three.js. Vite is the dev server and bundler (decided in the data pipeline ticket): `npm run dev` for local preview with world data served from the pipeline output, `npm run build` for the static site.
- Data: whole island, all roads, from OpenStreetMap. Real hills from an elevation model. Buildings and landmarks, weather and rain, sound and music are all in scope for v1.
- Art: stylized low-poly, flat-shaded, procedurally generated where possible.
- Regions are hand-curated named areas (the names people use), not official admin boundaries.
- Skills every session should consult: `/grilling` and `/domain-modeling` for grilling tickets, `/prototype` for prototype tickets, `/research` for research tickets. Glossary lives in `CONTEXT.md` at the repo root; keep it updated as tickets resolve terms.
- Research findings land in `docs/research/<slug>.md`. The project is not yet a git repository, so research is captured on the working tree rather than on `research/<name>` branches.
- Attribution matters: OpenStreetMap data is ODbL and must be credited in-game.

Detail: [docs/research/browser-traffic-simulation.md](../../docs/research/browser-traffic-simulation.md)

- [Research: OpenStreetMap road data for Bali](issues/01-osm-bali-road-data.md) — no Bali-only extract exists; download Geofabrik nusa-tenggara (167 MB, daily), clip offline with osmium to province relation 1615621, filter highway ways, export GeoJSONSeq with a tag whitelist, then pack to a custom binary (~149k ways, ~1.2M nodes, under 5 MB gzipped). Residential and living_street lanes are half the network and must stay. Tags are sparse, so lanes/width/speed/lighting default per class. Overpass is for exploration only. Attribution: "© OpenStreetMap contributors" linked to the copyright page. Detail: [docs/research/osm-bali-road-data.md](../../docs/research/osm-bali-road-data.md)
- [Research: OSM buildings, land use, and landmarks in Bali](issues/05-osm-bali-buildings-landuse.md) — OSM building footprints are near-complete island-wide; gap-fill only Jembrana, Gilimanuk, interior Gianyar/Bangli and south Nusa Penida from Microsoft/Google footprints. Treat all farmland as rice paddy, merge wood and forest, take land/sea from OSM land polygons, find temples via place_of_worship + hindu. Official desa (admin_level 7) and kecamatan (6) boundaries are complete and make a better base for curated regions than place nodes, which miss Uluwatu, Nusa Dua, Berawa, Umalas and others; a ~45-row seed region table is in the findings. Detail: [docs/research/osm-bali-buildings-landuse.md](../../docs/research/osm-bali-buildings-landuse.md)
- [Task: download the Bali OSM extract and report what is in it](issues/06-download-inspect-bali-osm.md) — data is local in `data/` and rebuilds in seconds with osmium; clipped to the island relation (Nusa Penida excluded). 146.7k road ways, 25,548 km; residential/living_street/service are 81% of ways, main network only 15% of km, paths and tracks 17%; tags sparse enough that width, lanes, speed and lighting must be per class. Canggu sample ready for the real-roads prototype. Detail: [docs/research/bali-osm-inventory.md](../../docs/research/bali-osm-inventory.md)
- [Prototype: low-poly art direction scene](issues/07-low-poly-art-direction.md) — "Golden hour": flat-shaded MeshStandard, muted earthy palette, warm exponential haze tied to the sky horizon colour, ACES tone mapping, gradient sky dome, no outlines. Dusk is the hero moment; night stays readable and moonlit with warm emissive accents. Palette hex values and lighting targets in the ticket; prototype at `prototypes/art-direction/`.
- [Prototype: real Bali roads rendered in three.js](issues/08-osm-roads-in-threejs.md) — all of Canggu (5.8k ways, 382k triangles) renders in 32 draw calls at 85 fps with mitred ribbons and round caps at every node. Widths: OSM width tag first, then Bali-calibrated per-class defaults (secondary 5.5 m, residential 3.5 m, gang 2.2 m); every class rendered, paths as thin decoration; colour by surface tag. Defects for later tickets: mitre spikes on sharp bends, dashes through junctions, one junction gap. Prototype at `prototypes/osm-roads/`.
- [Grilling: which regions exist and how the game knows you are in one](issues/09-region-list-and-detection.md) — about 45 regions built by unioning OSM desa boundaries under tourist names, with hand-cut polygons for a few (Uluwatu, Berawa, Petitenget); two-level nesting shown as "Berawa · Canggu"; kecamatan name as the fallback so nothing is nameless; persistent small label, no banner; two-second debounce at borders; runtime lookup from a baked 25 m region-id raster; authored as one regions file of OSM ids plus overrides. Initial list in the ticket.
- [Grilling: how the bike handles](issues/10-bike-handling-model.md) — hybrid: hand-written kinematic motion (one automatic scooter, ~90 km/h, punchy but realistic, slope affects speed) with Rapier as the collision layer (kinematic character body against building, wall and traffic colliders). Rideable anywhere on land with per-surface speed caps and wobble, including sand, paddies, steps and wading water; collisions bump, slow and carry on.
- [Grilling: the day/night cycle](issues/11-day-night-cycle.md) — strictly real Bali time with no override; real sun and moon position from a solar library; keyframed lighting curves over sun elevation, golden hour as short as reality; headlight, class-placed street lamps, emissive windows and traffic lights at night; one sun shadow map fitted around the bike, off at night.
- [Grilling: camera and controls](issues/12-camera-and-controls.md) — third-person chase camera only, pulling back and widening with speed, rolling with lean, lagging the heading, shaking on impact, never clipping into buildings; keyboard only (W/S, A/D, Shift brake, R reset); mouse-drag free look that snaps back; no photo mode.
- [Grilling: world scale and coordinate system](issues/13-world-scale-and-coordinates.md) — 1:1 metres; UTM zone 50S (EPSG:32750) with a fixed island-centre offset (E0 287,500, N0 9,065,500); three.js Y-up frame with x east and z south; 1 km chunk grid aligned to the origin with chunk-local geometry; world root rebased when the camera drifts 2 km. One shared lon/lat-to-world function for pipeline and runtime.
- [Grilling: how roads are represented in the game](issues/14-road-network-representation.md) — graph classes are motorway down to service plus living_street; tracks and paths render but are not in the graph; traffic honours oneway, player is free; bevel joins with round caps at every node, no special junction geometry; centre lines on tertiary and above clipped at junctions; bridges raised by layer with deck and railings; proposed, construction and raceway dropped; node-edge polyline graph stored per chunk with border-split edges; three baked LOD tiers per chunk.
- [Grilling: terrain](issues/15-terrain.md) — 30 m flat-shaded grid per chunk with 60 m and 120 m far tiers; terrain flattened under roads before roads are sampled from it; per-vertex land-cover colour from OSM polygons plus a raster fallback; synthesised terrace steps on sloped farmland; rivers cut shallow channels; terrain clipped to land polygons with a flat sea plane at zero and a synthesised beach strip; heights 1:1; runtime height from a bilinear heightfield lookup.
- [Grilling: the traffic model](issues/16-traffic-model.md) — in-house IDM traffic on lane centrelines derived from the graph, left-hand; 70% scooters with lateral filtering and overtaking; density per edge by class and region times a real-clock rush-hour curve; class priority with gap acceptance, roundabouts, and fixed-cycle lights only at OSM-tagged signals (483); the bike is a vehicle in the model; ~80 vehicles in a 400 m window; parked vehicles as props; 20 Hz sim in a Web Worker, instanced low-poly kit.
- [Grilling: buildings and landmarks](issues/17-buildings-and-landmarks.md) — OSM footprints gap-filled with Microsoft where sparse; heights from area and land use with tag overrides and deterministic jitter; hip and gable terracotta roofs on houses, flat on large blocks; window colour bands, compound walls on residential footprints, awnings on shopfronts; a procedural temple kit on all 2,132 Hindu temples; bespoke models for Tanah Lot, Uluwatu, Ulun Danu Bratan, Besakih, Handara and Lempuyang gates plus the airport from aeroway tags, placed from a landmarks file of OSM ids; three LOD tiers.
- [Grilling: weather and rain](issues/18-weather.md) — live real weather from a keyless forecast API sampled at eight points across the island, nearest sample blended as you ride; clear, partly cloudy, overcast, rain and storm; rain particles, wet darkened roads, denser haze and dimmer light via the lighting curves; cloud shadows scroll with wind, no cloud geometry; slight sway and longer braking in the wet; quiet seasonal simulation when offline.
- [Grilling: data pipeline architecture](issues/19-data-pipeline-architecture.md) — TypeScript pipeline shelling out to osmium and GDAL, sharing projection and geometry code with the runtime; eight stages from source fetch to packed blobs, global graph and terrain steps then per-chunk parallel builds, incremental by content hash, one command; Vite dev server and build for the game; custom binary blobs per layer per tier parsed in a worker; a global bundle (manifest, region raster, tables, asset kit) before the first chunk; rings 1.5, 4 and 9 km with hysteresis and a 300 MB memory budget; about 400 MB on disk, under 15 MB to first ride.
- [Grilling: roadside props and vegetation](issues/20-roadside-props-and-vegetation.md) — four prop sets (vegetation, roadside culture, infrastructure, beach) from CC0 packs recoloured plus hand-modelled Bali pieces; deterministic rule-based scatter per land cover and road-edge class avoiding roads, footprints and water; lush within 80 m of roads and thinner in interiors; BatchedMesh per chunk with a far mesh at 60 m, billboards in tier 1, none in tier 2; colliders near the bike; vertex-shader wind scaled by live weather.
- [Grilling: discovery and progress](issues/21-discovery-and-progress.md) — position, heading and visited regions and landmarks saved in localStorage with a versioned format and a "start fresh" option; discovery is a quiet count in the pause menu and marks on any map screen, no toasts or rewards; first ride starts on Jalan Raya Canggu facing north.
- [Grilling: the HUD](issues/22-hud.md) — minimal editorial text with no boxes: region label and road name bottom left, real clock and weather glyph top right, speed bottom right, a rotating corner minimap top left; M opens a pausing full-screen island map with visited regions shaded; Esc pause menu with resume, map, discovery counts, audio slider, credits and start fresh; loading screen carries the required attribution lines.
- [Grilling: sound and music](issues/23-sound-and-music.md) — sampled scooter engine crossfaded by speed with a wind layer; ambience beds by land cover and real time of day, gamelan near temples, weather layer with delayed thunder; eight nearest traffic vehicles voiced, horns and one impact set; no music; CC0 libraries plus Bali field recordings with a licence manifest; three buses, about 24 voices, one master slider, audio unlocked on first key press.
- [Grilling: hosting and deploy](issues/24-hosting-and-deploy.md) — Vite site on Cloudflare Pages, world data in R2 behind a custom domain for zero egress; immutable versioned world paths with pre-compressed Brotli and a short-lived manifest for atomic flips; site deploys from CI on push, world data published by a separate hash-based upload command; public from the first deploy.
- [Grilling: performance budget and level of detail](issues/25-performance-budget.md) — 60 fps at 1080p on an integrated-GPU laptop; under 150 draw calls, 1.5 M triangles, 8 ms GPU and 6 ms main-thread JS per frame; an automatic quality ladder (pixel ratio, shadows, props, traffic, tier radii) with an auto/low/high override in the pause menu; a scripted benchmark route recording frame times to JSON with a CI regression check.
- [Grilling: licensing, attribution and the credits screen](issues/26-attribution-and-credits.md) — MIT code and CC BY 4.0 hand-made assets; loading screen carries the OSM and Copernicus mandatory lines; a credits screen generated at build time from the asset manifest plus a hand-written data-sources section (OSM, Copernicus with the liability sentence, Microsoft footprints, land polygons, weather provider, libraries), failing the build if any asset lacks a licence entry.

## Out of scope

- Multiplayer or seeing other riders. Ruled out at the destination: single player.
- Mobile and touch controls. Ruled out at the destination: desktop browser only.
- Missions, delivery jobs, timers, scoring, or any fail state. Ruled out at the destination: free-roam.
- Realistic simulation physics, damage, and traffic rules enforcement. Ruled out at the destination: arcade feel.
- Any island other than Bali. Nusa Penida, Lembongan, and Lombok are not part of v1.
- An in-game map editor. Regions and landmarks are authored offline.
- Gamepad support, first-person view and a photo mode. Ruled out in [Grilling: camera and controls](issues/12-camera-and-controls.md): keyboard and the chase camera are enough for v1.
